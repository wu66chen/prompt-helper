# 坚果云同步指南

[返回首页](../README.md) · [使用指南](usage.md)

WebDAV 是让应用通过网络读写文件的协议。这里由提示词助手把资料库保存到你的坚果云文件夹；不使用云同步也可以正常使用本地功能。

## 1. 创建应用密码

登录坚果云网页端，进入「账户信息 → 安全选项 → 第三方应用管理」，添加一个应用密码，例如命名为“提示词助手”。操作入口以[坚果云官方说明](https://help.jianguoyun.com/?p=2064)为准。

复制生成的应用密码。它与网页登录密码不同，脚本需要的是应用密码。

## 2. 保存配置并首次同步

在提示词助手中打开「设置 → 云同步」，填写：

| 字段 | 填写内容 |
| --- | --- |
| 服务地址 | 固定为 `https://dav.jianguoyun.com/dav/`，无需修改 |
| 坚果云账号 | 你的坚果云账号，通常为注册邮箱 |
| 应用密码 | 刚生成的第三方应用密码 |
| 同步文件夹 | 默认 `PromptHelper`；所有设备填写相同值 |
| 启用自动同步 | 首次可先保持关闭，确认手动同步成功后再开启 |

依次点击「保存配置」「测试连接」「立即同步」。成功后，同步状态会显示上次成功时间。脚本自动创建同步文件夹，提示词保存在其中的 `prompts-v3.json` 文件内。

其他浏览器或设备安装脚本后，使用同一坚果云账号和同步文件夹配置连接，再执行同步。已有内容会合并，两个设备同时修改同一条内容时会保留冲突版本。

3.11.0 起，修改过的内置工具提示词和自定义工具也参与同步，包括删除和恢复内置操作。现有本机工具会自动迁移，原始记录仍保留；工具草稿不上传。同步后可在「优化 Prompt」查看，冲突时选择要保留的版本。

本次备份格式由 v3 升为 v4，新版仍能读取 v3 文件，云端文件名继续使用 `prompts-v3.json` 以沿用原有同步位置。请先将所有设备更新至 3.11.0 或更新版本并刷新网页，再同步；旧版无法读取 v4 文件时会停止同步，不应删除云端文件或通过覆盖来绕过版本检查。

## 3. 启用自动同步

勾选「启用自动同步」，再次点击「保存配置」。修改后会延迟同步，至少间隔 60 秒；打开匹配网站时每 10 分钟检查云端。关闭浏览器后不会继续同步。

需要立即交换内容时，点击「立即同步」。离线时仍可在本地使用。

## 同步哪些数据

**同步**：提示词、收藏、标签、分组、修改过的内置工具、自定义工具及其修改／删除历史。

**不上传到提示词文件**：主题等界面偏好、窗口位置与大小、草稿、坚果云账号与应用密码。界面偏好仅在同一浏览器的同一脚本安装中共用。

云端 JSON 为明文，HTTPS 保护传输过程，不提供端到端加密。不要把密码或密钥放入提示词。JSON 备份同样需要妥善保管。

## 常见问题

| 提示或现象 | 检查与处理 |
| --- | --- |
| 账号或应用密码不正确 | 确认账号无多余空格，使用第三方应用密码而非登录密码；必要时重新生成 |
| 无法连接或超时 | 检查网络、坚果云可用性，以及 Tampermonkey 的跨域请求权限 |
| 请求过于频繁 | 稍后重试，避免连续点击同步 |
| 服务未返回可靠的版本标记，已停止上传 | 已保留本地内容。先导出 JSON，确认各端为新版并重试；持续出现时保留错误信息提交 Issue，不要删除云端文件来强制覆盖 |
| 两台设备内容不同 | 确认账号和同步文件夹完全一致，两端均执行同步；若有冲突提示，选择需要保留的版本 |

脚本使用远端版本校验避免盲目覆盖。无法确认版本时停止上传是数据保护行为。当前只允许连接坚果云官方 WebDAV 地址，不能填写其他服务的地址。
